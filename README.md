# 🔐 Cybersecurity Home Lab — Kali Linux & VirtualBox

## 📌 Overview
A hands-on cybersecurity lab built using Oracle VirtualBox and Kali Linux to practice virtualization, networking, and ethical hacking fundamentals.

## 🛠️ Technologies Used
- Oracle VirtualBox
- Kali Linux
- NAT Network
- Linux networking

## ⚙️ Configuration
- **Network:** `10.0.0.0/24`
- **Kali Linux IP:** `10.0.0.2/24`
- **Network Mode:** NAT Network
- **VM Snapshots:** Configured for recovery and testing
- **Shared Folders:** Host-to-VM file sharing
- **Clipboard & Drag-and-Drop:** Enabled

## 🎯 Learning Objectives
- Understand virtual machines and virtualization.
- Practice subnetting and IP address configuration.
- Learn virtual network configuration.
- Build a Linux environment for cybersecurity practice.
- Prepare an isolated lab for future security testing.
